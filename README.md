# Book Cinema Studio

一个面向读书短视频的**逐镜头质量控制台**。第一版重点是可控画面，而不是一键生成不可编辑的视频。

## 运行

打开 `index.html` 即可离线使用。也可通过 GitHub Pages 托管，但当前仓库是公开的，请**不要上传原书全文、私人配音或未授权素材**。

## 已实现

- 9:16 白板手绘预览（Canvas SVG 风格）
- 镜头增删、排序、独立编辑文案、主题、时长、绘制速度和配色
- 单镜头/全片播放与时间轴拖动
- 当前帧 PNG 下载、项目 JSON 导入导出
- 本地浏览器自动保存
- 在支持的浏览器导出无声 WebM

## 尚未实现

- 已确认的《走出戈壁》正式脚本导入与原书事实校验
- AI 画面生成、跨镜人物一致性、复杂逐笔描摹
- 配音、字幕对齐、背景音乐、MP4 合成
- 自动测试及部署

## 使用建议

先逐镜确认画面质量，再开发配音与成片链路。视频导出使用实时 Canvas 录制，时长和帧率可能受浏览器性能影响。
